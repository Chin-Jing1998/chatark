# ChatArk 界面多方案调优设计说明

- **修订作者**：`Chin_Jing1998`
- **修订日期**：2026-10-31（北京时间）
- **目标视口**：桌面端 `1320×860`（最小窗口兼容 `960×620`；M3E Canvas 桌面画框 `1280×800`）

## 1. 用户任务与核心动作

- **目标用户**：重度使用 Claude Code 的开发者与知识工作者，需在本地管理上千条历史会话归档。
- **核心任务**：按分类/项目/标签/星标快速浏览会话、运行 FTS5 全文搜索（`⌘K`）、在多标签舞台中对照阅读长对话与工具调用代码、管理 6 套外壳与 `convo://` 阅读器联动主题预设。
- **现状痛点**：
  1. `TopBand`（40px）与 `Stage` 标签条（40px）上下叠放占用 80px 垂直空间，且顶栏仅居中放置应用标题；
  2. `ConversationItem` 在树形侧栏将置顶、星标、标题与模型徽章挤压在单行，长标题易截断且缺少时间/消息数层级；
  3. 主舞台空状态仅有三个裸文字快捷键链接，缺少库规模概览、最近会话直达与未导出会话补录入口；
  4. `SettingsDialog` 采用单列长滚平铺，缺少左侧分区锚点导航。

## 2. 三套跨风格与骨架候选方向

| 维度 | 方案 A：M3E 色调容器工作台 (`option-a-m3e.html`) | 方案 B：高密度档案检索台 (`option-b-archive.html`) | 方案 C：精致层叠液态玻璃 (`option-c-glass.html`) |
| --- | --- | --- | --- |
| **设计北极星** | 以 Material 3 Expressive 色调容器与内嵌圆角舞台建立清晰的功能分舱与动态反馈 | 以代码与文献档案室的高对比度、等宽数字索引与单行 42px 顶栏让位于高频检索与长文阅读 | 保留 macOS 原生液态玻璃与 6 套预设基因，通过 1px 内高光边缘与悬浮岛式导航提升精致度 |
| **首屏骨架** | 左侧胶囊活动栏（64px）+ 圆角分组树侧栏（272px）+ 内嵌 24px 大圆角主舞台画布（顶栏与标签合流） | 单行 42px 一体式标题标签带（集成五视图胶囊、标签页与全局检索）+ 双行等宽索引侧栏 + 全幅编年体舞台 | 悬浮磨砂胶囊 `IconRail` 岛 + 分层半透明侧栏 + 集成目录抽屉与 6 预设色点的浮层玻璃舞台 |
| **对话阅读器** | 无左粗线、按角色区分底色阶梯的 20px 圆角容器；工具调用合流为胶囊状态条 | 左栏 124px 等宽时间/角色编号锚点 + 右栏宽幅正文的编年体排版；工具调用为紧凑终端折叠条 | 内高光玻璃卡片头 + macOS 窗口式文件名代码块顶栏；左上浮动目录触发器带滑出玻璃抽屉 |
| **空状态与设置** | 3 卡库规模仪表盘 + 最近会话双列卡；双栏分区设置配 6 套主题色板卡片 | 高密度 FTS5 检索台账表格；双栏档案规格设置弹窗 | 玻璃 KPI 仪表盘；带实时折射切换的双栏设置弹窗 |
